# 开发与验证

应用只依赖 Python 标准库。本地开发优先使用 uv：

```text
uv venv --python 3.11
uv run --no-project python tools/test_policy.py
uv run --no-project python tools/test_controller.py
```

安装飞牛官方 fnpack 1.2.3 后构建：

```text
uv run --no-project python tools/build.py --fnpack /path/to/fnpack
```

构建脚本只复制 FPK 所需目录到临时目录，排除缓存；产物写入 `dist/`。

没有 fnpack 时，可用本地备用打包脚本生成相同目录结构和 `md5(app.tgz)` 校验和的 FPK：

```text
python3 tools/build_local.py
```

本地脚本用于安装验证，正式发布仍建议使用官方 fnpack。

## 发布

推送 `v*` 标签会触发 [release.yml](../.github/workflows/release.yml)。工作流先校验标签与 `manifest` 版本一致，再运行本地测试，使用官方 fnpack 1.2.3 构建 FPK，最后把 `oes-fancontrol_<version>_arm.fpk` 和 `SHA256SUMS` 上传到 GitHub Release。标签版本不一致时工作流直接失败。

`tools/probe.sh` 只读取系统硬件信息，不写 GPIO、不加载驱动。`tools/test_hardware.py` 和 `tools/verify_installed.py` 是实机验证脚本，会改变风扇状态、暂停原控制服务或重启应用服务，需先阅读并在确认的 OES 硬件上使用。它们不会自动执行。

本项目的硬件测试验证 GPIO 输出回读，不包含风扇测速反馈。完整测试范围和限制见根目录 README。

项目开发时参考了飞牛官方应用文档，以及社区项目 [oesp-fanctl](https://github.com/wangbujiangwude/oesp-fanctl) 提供的硬件线索。本项目控制逻辑使用独立实现的 GPIO ioctl、双进程服务和权限隔离；硬件参数以实机设备树验证为准。
